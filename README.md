The Online Examination System is a web-based application developed to automate and manage the examination process efficiently. It reduces manual work involved in traditional exams and provides instant result evaluation. The system has two main modules: Admin and Student. The Admin can create exams, add questions, and view results, while students can register, log in, attempt exams, and view their results.
The application is built using Java, Spring Boot, Hibernate, Thymeleaf, HTML, CSS, and MySQL. The system automatically calculates marks and stores results securely in a database. It provides a user-friendly interface and ensures proper data management.
This project simplifies exam management and improves accuracy, efficiency, and reliability in conducting online examinations.
